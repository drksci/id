Discovery and onboarding

Agents may discover this page from /.well-known/agent-access.json or MCP metadata. Auto-discovery can mark a new service pending while it checks repository, workspace parent, environment, and DNS CNAME/TXT evidence. Pending records do not issue grants. Use first-touch onboarding to request provider setup with explicit human approval.
